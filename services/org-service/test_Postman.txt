=======================================================
IDENTITY SERVICE (Port 8088)
=======================================================

// 1. Lister les utilisateurs
GET http://localhost:8088/api/users

// 2. Créer un utilisateur (Manuel)
POST http://localhost:8088/api/users
{
  "clerkId": "user_2Pz...",
  "organizationId": "VOTRE_ID_ORG",
  "email": "jean.dupont@exemple.com",
  "firstName": "Jean",
  "lastName": "Dupont",
  "role": "EMPLOYEE"
}

// 3. Provisionner un utilisateur (Auto-sync)
POST http://localhost:8088/api/users/provision
{
  "clerkId": "user_2Pz...",
  "email": "jean.dupont@exemple.com",
  "firstName": "Jean",
  "lastName": "Dupont",
  "role": "ADMIN"
}

// 4. Utilisateur actuel (Nécessite un Token Clerk)
GET http://localhost:8088/api/users/me
Authorization: Bearer <CLERK_JWT_TOKEN>
